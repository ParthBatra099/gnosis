# GNOSIS - Enterprise Data Security Platform

## Overview
GNOSIS is an enterprise data-security platform. This codebase represents **Phase 1: Project Foundation**, establishing the base backend infrastructure, PostgreSQL database connection, configuration system, migration baseline, and health monitoring.

---

## Prerequisites
* Python 3.12.x
* PostgreSQL 14+ running locally or via container

---
